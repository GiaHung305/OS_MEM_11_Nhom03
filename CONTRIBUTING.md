# Quy tắc cộng tác – Nhóm 03

## Task và branch
Mỗi task có Task ID, người phụ trách, reviewer và deadline.
Cập nhật main trước khi tạo branch. Ví dụ: chore/QT01-01-repo-setup hoặc feat/QT02-01-select-strategy.

## Commit và pull request
Commit theo một thay đổi có ý nghĩa, kèm Task ID.
Ví dụ: feat: implement first-fit selection [QT02-01].
PR ghi Task ID, thay đổi, cách kiểm tra, kết quả và link minh chứng.
Reviewer kiểm tra trước khi merge; không tự ghi task hoàn thành khi chưa review.

## Tiến độ tuần
Mỗi người cập nhật report/weekly/week_XX.md với task, kết quả, link commit/PR, vướng mắc và kế hoạch tiếp theo.
Task chỉ hoàn thành khi đủ deliverable và reviewer xác nhận.

## File và dữ liệu
Không commit mật khẩu, token, .env, file build hoặc cấu hình cá nhân.
Lưu CSV mẫu đã kiểm tra trong input/ và output/.
Tách thuật toán khỏi GUI; dùng UTF-8 cho tài liệu và thống nhất định dạng CSV ở task đặc tả.

## Nguồn và AI
Trích dẫn nội dung mượn; ghi việc sử dụng AI và cách nhóm tự kiểm chứng trong báo cáo.
